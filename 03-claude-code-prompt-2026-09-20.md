# Task Monitor — Claude Code executor prompt

_Generated by Ideon on 2026-09-20 for release v0.1. Paste the block below into Claude Code._

## How to run this

### Before the first run (one-time setup)

- Node.js is installed: in a terminal, `node -v` prints a version (22 or 24). If not, install it from nodejs.org.
- Claude Code is installed and signed in: run `npm install -g @anthropic-ai/claude-code`, then type `claude` once and follow the sign-in link with your Claude account. Type `/exit` to leave.
- Your app runs: you can start task-monitor yourself the way you normally do, and it works before Claude Code touches anything.

### Steps (once per iteration)

1. Download the executor pack from Ideon → Execute and unzip it. Move its files into the app folder, next to package.json: 02-audit-2026-09-20.md, audit-and-task-2026-09-20.xlsx, task-status.md and this prompt file.
2. Open a terminal in the app folder and start Claude Code there: `cd /Users/aldenrayejorango/Developer/PROJECTS/task-monitor && claude`. Run `ls` first — it should list package.json and the files above.
3. Start Claude Code in that terminal: type `claude` and press Enter. The first time in a folder it asks whether you trust the folder — answer Yes.
4. Copy the whole prompt block below, paste it into the Claude Code box and press Enter. That is the only thing you type.
5. Let it work. It goes down the task sheet top to bottom: implements a row, runs the tests, estimates that row's AI cost, appends one YES (or BLOCKED with a reason) line plus its cost estimate to task-status.md, adds a CHANGELOG line and commits. Answer Yes when it asks permission to run a command or edit a file. It skips rows whose column R is On-Hold; release one by setting it to Proceed in Ideon → Tasks and exporting the pack again. Open task-status.md at any time to watch progress live. If it stops early or your computer sleeps, paste the same prompt again — logged rows are not redone.
6. When it prints the totals (done, blocked, on-hold), start the app the way you normally do and test what changed (Checkpoint B). Then go to Ideon → Tasks, press "Sync from Claude Code" and pick task-status.md from the app folder — every row it finished is marked here in one go. Then go to Ideon → Iterate and paste what you found, or name one section to sweep.

### If something goes wrong

- "Cannot find 02-audit-2026-09-20.md" or the xlsx: the files are not next to package.json, or the pack was downloaded on a different day than this prompt. Move the files, or generate the prompt again and download a fresh pack so the dates match.
- Claude Code says you are not signed in: type `/exit`, run `claude` on its own, complete the sign-in, then start again from step 3.
- A row came back BLOCKED: read the reason on its line in task-status.md (or column O of the Excel file), then paste your decision into Ideon → Iterate — the next audit turns it into a new row.
- The run ended but the Excel file still looks untouched: that is only the final sync step failing — task-status.md has every result. Upload that file in Ideon → Tasks → "Sync from Claude Code" instead.
- You want to undo a task: every task is its own git commit named "T-00xx: title", so a developer can revert one without touching the others.

A row is already finished if task-status.md has a YES line for it, or column N is "YES". Never redo a finished row.

   - Add/extend automated tests per column M; run the full test suite (npm test); fix anything you broke.

5. LOG IT NOW — the moment the row's tests pass, before the changelog, before the commit, before you read the next row.

c. Print: total done, total blocked (with IDs), total On-Hold (with IDs — these need my review), the total estimated
