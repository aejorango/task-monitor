# Archived docs

These described how the app was first built, in 2025. They are kept for history
and are **out of date** — do not follow them:

- `BUILD-GUIDE-2025.md` — describes anonymous auth, GitHub Pages hosting and a
  `/task-monitor/` base path. The app now uses Google sign-in with an approval
  gate, deploys to Firebase Hosting, and serves from the root.
- `package-scripts-2025.md` — describes the original two npm scripts. The
  current set is in `package.json` and explained in the root `README.md`.

For how to run, configure and deploy the app today, see the root
[README.md](../../README.md). For architecture and conventions, see
[CLAUDE.md](../../CLAUDE.md).
